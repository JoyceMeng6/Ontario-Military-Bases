# Ontario-Military-Bases
This personal project maps the locations of the Ontario military installations that are currently active, including proximity analysis to the Canada &amp; U.S. Border.
[Date Started]: August 2026

# Process:
- Sourced geographic coordinates from Wikipedia.
- Cleaned the coordinates (DMS to DD) using Excel formulas to create a dataset.
- Utilized the XY Table to Point tool to turn Excel data into a shapefile.
- Colour-coded bases by branch (Army, Navy, Air Force, etc.)
- Utilized the Near analysis tool to calculate the proximity of each installation to the Canada/US border.
- Visualized findings in a professional map layout with a supporting bar chart.
- Created a web map from this data on ArcGIS Online (Map Viewer.)
- Self learned Arcade to stylize and create informative pop-ups.
